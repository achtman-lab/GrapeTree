**Using GrapeTree**

GrapeTree is an interactive tree visualisation program within [EnteroBase](https://enterobase.warwick.ac.uk/), supporting changes to tree layout and metadata. It generates trees using neighbour joining, the classical minimum spanning tree algorithm (MSTree), or the improved MSTreeV2 algorithm.

The stand-alone version runs a lightweight webserver on your computer. You interact with the program through a web browser, as you would in EnteroBase. We recommend Google Chrome for best results.

[Detailed documentation](https://enterobase.readthedocs.io/en/latest/grapetree/grapetree-about.html)

**Running on Mac: Download GrapeTree-3.0.0-macOS-Intel.zip**

Unzip the archive and drag `GrapeTree.app` into your Applications folder. This is an Intel Mac application; Apple silicon Macs require Rosetta 2. The application is unsigned and not notarised, so macOS may require you to allow it in Privacy & Security.

**Running on Windows: Download GrapeTree-3.0.0-Windows.zip**

Unzip the archive, open the extracted `GrapeTree` folder and run `GrapeTree.exe`. Keep the other files in that folder. The application is unsigned, so Windows may show a SmartScreen warning when you first run it.

**Running with Python**

Python 3.10–3.14 is supported. Install GrapeTree and start the local application with:

```sh
python -m pip install grapetree==3.0.0
grapetree
```

To calculate a tree on the command line:

```sh
grapetree --profile profiles.tsv --method MSTreeV2 > tree.nwk
```

**Running in the browser: Download GrapeTree-3.0.0-browser.tar.gz**

Extract the archive and serve the `GrapeTree-browser` directory using a local webserver. For example, run `python -m http.server 8000` from that directory, then open `http://localhost:8000/browser-wasm/`. Profile calculations run locally in the browser using MSTree, MSTreeV2, NJ or RapidNJ. This browser-only application is separate from the Python-backed application above.

**Source code**

Source code is available in tar.gz or zip format. The Python source distribution is `grapetree-3.0.0.tar.gz`. Docker build instructions are in the README. Checksums for the uploaded release files are provided in `SHA256SUMS`.

**Change Log**

* Updated Python support and packaging, including wheel and source installations, Windows and Intel Mac application builds, and Docker support. Python 2 is no longer supported.
* Added browser-only tree calculation using WebAssembly, without a Python backend.
* Added command-line GrapeTree JSON, GraphML, CSV and JSON network exports, and cluster membership export at multiple thresholds.
* Added `--total-loci` for MSTreeV2 calculations from SNP-only alignments.
* Fixed selected-node collapse, remote tree loading, long-branch controls, metadata table positioning, grouped labels and MicroReact export handling.
* Fixed browser tree calculations to preserve the Python implementation's tie handling, branch distances and rounding.
* Fixed network exports when sample names resemble internal node IDs, and metadata import containing quoted multiline fields.
* Fixed complete deletion (`--missing 1`) to retain loci called in every sample, and made the `--wgMLST` option take effect. These corrections can change results compared with previous versions.
* Rejects duplicate sample IDs, including IDs that become identical after sanitisation.
* Restored Ninja compatibility with modern Java, removed the Numba dependency, and fixed Conda builds to use the main development branch.
* Keeps `MSTrees.py` as a single independently runnable script, now at `grapetree/module/MSTrees.py`. Update uses of the old `module/MSTrees.py` path or `import module.MSTrees`; the installed import is `from grapetree.module.MSTrees import backend`.
